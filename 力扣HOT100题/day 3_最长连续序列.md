## 题目描述

给定一个未排序的整数数组 `nums` ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 **O(n)** 的算法解决此问题。

 

**示例 1：**

```
输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。
```

**示例 2：**

```
输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9
```

**示例 3：**

```
输入：nums = [1,0,1,2]
输出：3
```

 

**提示：**

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 本课知识点(2026-09-05)

**1. 复杂度的乘法规则**:循环嵌套几层,操作次数 = 各层相乘。本题的三级跳:

- 暴力(在数组里查"在不在"):n 个起点 × n 次追问 × n 步扫描 = O(n³)
- 换哈希集合,"在不在"变 O(1):n 个起点 × n 次追问 = O(n²)
- 加"起点资格"剪枝:只有链头数链,每个元素最多被摸 2 次 = **O(n)**

**2. 集合(set)= 只有 key 的字典**:本题只需回答"某数在吗",连 value 都不用。Go 写法 `map[int]bool`:`m[x] = true` 存入,`if m[y]` 直接当条件用(取不到自动 false = 不存在),重复插入自动去重。

**3. 起点资格剪枝(本题灵魂)**:`x-1` 不在集合里,x 才是链头,才有资格数链;链的中间站全部跳过。数组里可能同时藏着多条链,每条链只被自己的链头数一次,答案取最大。

**4. 遍历集合 vs 遍历数组**:链头在数组里有重复时,遍历**数组**会把同一条链数多遍(最坏退化 O(n²),反例 `[1,1,…,1, 2,3,…,n/2]`);`for v := range m` 遍历**集合**才严格 O(n)。

**Go 语法积累**:`for y := x+1; m[y]; y++ {}` —— for 当 while 用;`len`/`min`/`max`/`cap` 是内置函数名,别拿来做变量名(会遮蔽)。

## 我的代码

```go
func longestConsecutive(nums []int) int {
    m := map[int]bool{}
    for _, x := range nums {
        m[x] = true
    }

    ans := 0
    for _, v := range nums {
        if !m[v-1] {
            len := 1
            for y := v + 1; m[y]; y++ {
                len++
            }
            if len > ans {
                ans = len
            }
        }
    }
    return ans
}
```

**批改后的严格 O(n) 版**(改两处:外层遍历集合 `for v := range m`;变量名 `len` → `cnt` 避免遮蔽内置函数):

```go
func longestConsecutive(nums []int) int {
    m := map[int]bool{}
    for _, x := range nums {
        m[x] = true
    }

    ans := 0
    for v := range m {          // 遍历集合:每个不同值只处理一次
        if !m[v-1] {
            cnt := 1
            for y := v + 1; m[y]; y++ {
                cnt++
            }
            if cnt > ans {
                ans = cnt
            }
        }
    }
    return ans
}
```
