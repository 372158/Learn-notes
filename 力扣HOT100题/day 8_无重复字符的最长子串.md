# 3. 无重复字符的最长子串 (Longest Substring Without Repeating Characters)

> 难度:中等 | 分类:滑动窗口
> 来源:[力扣 HOT 100 - Day 8](https://leetcode.cn/problems/longest-substring-without-repeating-characters/description/?envType=study-plan-v2&envId=top-100-liked)
> 状态:✅ 已完成(学生在老师引导下解出,2026-09-10)

## 题目描述

给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长 子串 **的长度。

 

**示例 1:**

```
输入: s = "abcabcbb"
输出: 3 
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。
```

**示例 2:**

```
输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。
```

**示例 3:**

```
输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。
```

 

**提示：**

- `0 <= s.length <= 10^5`
- `s` 由英文字母、数字、符号和空格组成

## 我的思路

<!-- 先自己想,把想法写在这里;卡住了向老师要提示 -->

**(2026-09-10,师生共建)** 滑动窗口 = 同向双指针 + 哈希"上次位置"。

- **结构**:快慢指针的亲戚,left/right 都从左出发,right 在前。
- **循环不变量:窗口 [left,right] 内无重复字符**
- **动作**:right 每轮无条件扩张吃一个字符;一旦窗口非法(撞到窗口内已有字符),left 收缩到"旧冲突字符下标+1";right 左侧被撇出的字符,其历史记录作废
- **哈希升级**:Day 1 问"出现过吗",今天问"上次出现在哪" → `map[byte]int`,字符→最后下标
- **O(n)**:两根指针只前进不后退,合计至多 2n 步;遇到重复 left 只跳冲突段,窗口其余合法部分直接继承

## 我的代码(终版,Go,2026-09-10)

```go
func lengthOfLongestSubstring(s string) int {
    m := make(map[byte]int) // 字符 → 最后一次出现的下标
    left, ans := 0, 0
    for right := 0; right < len(s); right++ {
        if last, ok := m[s[right]]; ok && last >= left { // comma-ok:真出现过且落在窗口内
            left = last + 1 // left 收缩到旧冲突字符后一位
        }
        m[s[right]] = right // 更新最新位置
        ans = max(ans, right-left+1)
    }
    return ans
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```

**批改 = 通关(修正一处)**。学生一稿结构与四步骤全对,但丢 comma-ok 导致真 bug:Go 里 `m[key]` 对不存在的 key 返回零值 0(int 的零值),于是"从没出现过"和"正好在下标 0 出现过"返回同一个 0 → 首字符被误判为"在 0 出现过",`s="ab"` 会错算成 1。修复:改 comma-ok `if last, ok := m[...]; ok && last >= left` —— 既要"真的出现过(ok)",又要在当前窗口内(last>=left)。用例:`"ab"→2`、`"pwwkew"→3`、`"abcba"→3` 验算通过。

## 复杂度分析

- **时间复杂度:** O(n) —— right 走 n 步,left 合计至多 n 步,lookup O(1)。
- **空间复杂度:** O(min(n,字符集)) —— map 存字符串中出现过的不同字符;有限字符集(本题为 ASCII)时 O(1)。

对比暴力 O(n³):这就是把"每个子串都整个检查一遍"压缩成"窗口随走随维护、left 只在冲突时跳"。

## 关键知识点

1. **滑动窗口 = 为保证"窗口内满足条件"而同向移动的两根指针**;right 无条件扩张,left 只在不满足时收缩。O(n) 的关键:信息不丢弃(窗口其余部分继承)。
2. **陷阱:用 map 存下标时,"从没出现过"和"在 0 出现过"在 Go 里都返回零值 0** → 必须 comma-ok 区分。这是本题唯一的天坑,也是继"切片不能做 key"之后第二个 map 易错点。
3. **历史作废**:left 左侧的字符被撇出窗口后,其记录是"已作废的过去";`last >= left` 这层守卫把作废历史与真冲突分开。

## 总结

本题三个锚句:

1. **窗口 = 无重复的子串;right 无条件吃,left 只在非法时收缩**;
2. **查"上次在哪"用 map[字符]下标,但必须 comma-ok 排除零值误判**;
3. **left 左侧的旧记录是已作废的过去,last >= left 才作数**。

**本日纪律对照(Day 8 收编)**:**right 无条件扩张,left 只在非法时收缩** —— 与 Day 5(记账与挪动独立)、Day 6(先挪再跳)、Day 7(谁结算谁走)并列为指针纪律的第四格。
